Perguntas frequentes

Tire suas dúvidas sobre o app.

O app é gratuito?

Sim, as funções básicas são gratuitas. Há um plano premium com relatórios avançados e temas exclusivos.

Meus dados são seguros?

Esta versão é um projeto acadêmico: o cadastro vai para uma API rodando no seu próprio computador e some quando ela é desligada. Mesmo assim, não insira informações pessoais reais.

O app funciona para ciclos irregulares?

Funciona, mas as previsões ficam menos confiáveis quando os ciclos são irregulares.

Posso usar como método contraceptivo?

Não. O aplicativo é informativo e não deve ser usado como método contraceptivo. Consulte um profissional de saúde.
